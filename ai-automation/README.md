# Executive brief automation

`generate_brief.py` reads validated JSON outputs and creates `WEEKLY_BRIEF.md`. It needs no API key.

```bash
python3 ai-automation/generate_brief.py
```

Python owns calculations. A browser-based AI assistant may improve clarity using `skills/weekly-brief/SKILL.md`, but it may not recompute or invent numbers. A human checks every recommendation before distribution.

This is an honest no-paid-API implementation. It is MCP-ready, but does not claim that an MCP connector ran.
